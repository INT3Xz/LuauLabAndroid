# Luau Lab — مشروع تعليمي للأندرويد

تطبيق Android بسيط بواجهة Kotlin/Jetpack Compose ومحرك Luau أصلي بلغة C++.
المحرك يشغّل Luau محليًا داخل التطبيق، ويعرض ناتج `print` وأخطاء التحميل/التشغيل.

## ما الذي يفعله؟
- محرر نصوص لكتابة Luau.
- تشغيل محلي عبر Luau VM الرسمي.
- أمثلة جاهزة وزر تشغيل.
- إخراج Console محدود الحجم.
- لا يتصل بـ Roblox ولا يقرأ/يعدّل عمليات تطبيقات أخرى ولا يحقن ملفات DLL أو مكتبات.

## المتطلبات
- Android Studio حديث.
- Android SDK Platform 35.
- Android NDK و CMake 3.22.1 من SDK Manager.
- اتصال إنترنت في أول بناء؛ CMake يجلب Luau من مستودعه الرسمي عبر Git.

## فتح وبناء التطبيق
1. فك ضغط `LuauLabAndroid.zip`.
2. افتح مجلد `LuauLabAndroid` في Android Studio.
3. ثبّت SDK/NDK/CMake إذا طلب Android Studio ذلك.
4. انتظر Gradle Sync وتنزيل Luau أول مرة.
5. وصّل هاتف Android مع تفعيل USB debugging أو استخدم محاكيًا.
6. اضغط Run لتثبيت التطبيق.

## تجربة سريعة
اضغط Example ثم RUN. جرّب:
```lua
local message = "Learning Luau"
print(message)

for i = 1, 5 do
    print("step", i)
end
```
